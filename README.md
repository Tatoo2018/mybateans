# MyBateans - MyBatis Support for NetBeans IDE

[![Build Status](https://img.shields.io/badge/status-under--development-orange)](#)

---

## 🇺🇸 English

### 📝 Description
This plugin adds MyBatis support to the NetBeans IDE. Please note that this project is currently **under active development**.

### ✨ Key Features
- **Hyperlink Navigation**: Seamlessly jump to corresponding MyBatis mappers or SQL statements by clicking references in Java code or XML. This ensures high efficiency even in large-scale projects.

### 🌐 Update Center
Add the following URLs via `Tools` > `Plugins` > `Settings` in NetBeans to install and auto-update.

| Branch | Update URL |
| :--- | :--- |
| **Main** (Stable) | `https://tatoo2018.github.io/mybateans/updatesite/main/updates.xml` |
| **Develop** (Latest) | `https://tatoo2018.github.io/mybateans/updatesite/develop/updates.xml` |
